AIR GUITAR OPERA - ACOUSTIC GUITAR EDITION

This version uses WebAudioFont's sampled Acoustic Guitar (steel) preset.
It does not copy audio from Viola the Bird. Viola the Bird uses a proprietary machine-learning string synthesis system.

Upload these three files to the root of the GitHub Pages repository:
- index.html
- style.css
- app.js

Internet is required for MediaPipe and the sampled guitar library.
Use Chrome or Edge.
